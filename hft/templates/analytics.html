Сигнатуры: сравнение подходов

Нажмите «Сравнить подходы».

Сигналы — общая схема

Источники сигналов:
  1. Новостной конвейер — лексико-семантический скоринг текста → score ∈ [−100, +100] на семейство.
  2. ML-корреляции со сдвигом — лог-доходности, матрица Пирсона с лагом → пара «ведущий→ведомый».
  3. Подбор лага — лучший лаг по |r|, симуляция знаковой торговли → PnL (1 млн ₽).
  4. Стратегии gap/intraday — сигналы по разрывам цены, моментуму XAU и мультифактору (virtual_trader).
  5. Сигнатуры текста — TF-IDF/Hybrid/Lexicon → [−1, +1], валидация против будущей цены (Spearman ρ).

Новостной сигнал (news_scorer)

Поиск по 5 категориям: monetary · commodity · geopolitics · macro · demand.

impact = Σ_cat ( Σ_pos w − Σ_neg w ) conf = min( 0.3 + 0.12·min(hits, 8), 0.95 ) score = impact · fam_coef · (100/9) · (Σ_weights / 3) прямые упоминания: fam_coef = 1.0 косвенные (глоб.драйверы): fam_coef = 0.35 · 0.7 направл. += 0.12·100·fam_coef (bullish), −0.12·100·fam_coef (bearish) клиппинг: [−100, +100]

Параметры DEFAULT_PARAMS:

half_life_hours — 12.0 (полураспад влияния)
min_conf — 0.35 (порог уверенности)
agg — weighted (weighted|median|peak)
norm — 100.0 (шкала сигнала)
weights.monetary — 0.30
weights.commodity — 0.25
weights.geopolitics — 0.25
weights.macro — 0.10
weights.demand — 0.10

Семейства: GOLD, SILV, COPPER, PLATINUM_SPOT, BRENT, NGAS. Правило: если совпал >1 негативный + отсутствует позитивный маркер → aggr `bear`.

ML-корреляции со сдвигом (analytics_db)

Лог-доходность и матрица Пирсона со сдвигом: строка «ведёт» столбец.

r[i] = ln( c[i] / c[i−1] ) // лог-доходность ρ(x,y) = Σ(x−x̄)(y−ȳ) / √(Σ(x−x̄)² · Σ(y−ȳ)²) // Пирсон, попарно, n ≥ 5 mat[исх][цел] = ρ( logRet[исх][t], logRet[цел][t+lag] )

Пресеты лагов (баров):

LAG_PRESETS: 1d = [1,2,3,5,10,20], 60min = [1,2,4,12,24,48,72,144], 10min = [1,3,6,12,36,72,144,288,432]

Сигнал от подбора лага (ml_best_lags):

s = sign( logRet[source][t] ) // +1 / −1 / 0 gross = Σ s · logRet[target][t+lag] profit = gross · 1 000 000 − 0.00015·n·1 000 000 // условная комиссия 0,015% acc = доля совпадений знака s и return target

Экономика (ml_strategies, «Финам N6 Трейдер»):

FINAM_COMM = {futures: 1.2 ₽/контракт, spot: 0.025%} · BARS_PER_DAY = {1d:1, 60min:14, 10min:70}
trades_day = round(BARS_PER_DAY / lag), contracts = int(1 000 000 / avg_close), fee = 2 · fee_per_trade · n

Наиболее доходные стратегии (модель на 1 000 000 ₽)

Стратегия: по знаку логдоходности источника (source) в момент t открываем позицию в цели (target) на лаг баров. Ликвидность и цены — по фактическим сделкам MOEX (60 min, ~5 дней). Комиссия: фьючерсы до 1,2 ₽/контракт, spot/ETF до 0,025%.
Нажмите «Рассчитать стратегии».

## Сводка
День (20.08): **новый источник данных о портфеле — Finam Trade API**. Сейчас
портфель собирается только из Tinkoff (`tinkoff_invest_daemon.py` →
`parsers/invest/invest_portfolio.db`), график (`invest_chart.js`) и виджет
(`invest_banner.js`) читают его через `/api/invest/history` + `/api/invest/tickers`.
Решено (владелец): **общая БД** — новый демон `finam_invest_daemon.py`
пишет портфель Finam в ту же `invest_portfolio.db` (те же таблицы), фронтенд
подхватывает автоматически; в API/JS добавляется метка источника
(`finam` / `tinkoff`).

Документация Finam: `https://api.finam.ru/getting-started/` — JWT получается
`POST /v1/sessions {"secret": ...}` (15 мин), портфель — `GET /v1/accounts/{account_id}`
с заголовком `Authorization: Bearer <jwt>`. Позиции: `symbol`, `quantity.value`,
`current_price.value`; валюты — `cash[]` (units/nanos). Лимит 200 req/min.

Цель дня (владелец): **портфель Finam виден на графике и в инвест-виджете**
вместе с Tinkoff (общая БД), источник данных обозначен бейджем в панели.

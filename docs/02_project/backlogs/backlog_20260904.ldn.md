## Задачи

### Цель №1 — Ось X и метки
- TICK-01 ✅ (H) — метки времени на оси X: угол 0° (`maxRotation/minRotation:
  0`), `padding: -30` → внутрь графика, на 30px выше оси X.
- TICK-02 ✅ (M) — метки цвета по знаку суточного изменения: красный `< 0`,
  зелёный `≥ 0` (через `ctx.tick.value`, не `ctx.index`).
- TICK-03 ✅ (M) — лейблы суточных приростов только на 00:00-полночь,
  без `%` и без времени; позиция под осью (`chartArea.bottom + 10`).
- TICK-04 ✅ (S) — отступ снизу графика: `layout.padding.bottom 20 → 23px`;
  метки времени — `padding: -30`.

### Цель №2 — Стековые заливки TGLD/TMON/LQDT
- FILL-01 ✅ (H) — слои стека заливаются к **нижестоящему** слою, а не к
  origin: `fill: '-1'` для TMON/LQDT, `fill: origin` для TGLD. Штриховка
  LQDT идёт от уровня TGLD, а не от нуля.
- FILL-02 ✅ (H) — при отключении TMON/LQDT область TGLD больше не
  «закрашивается»: TGLD `fill: origin` (к нулю), а не к следующему слою
  в стеке.
- FILL-03 ✅ (H) — нулевые участки (нет позиций) не штрихуются: доли
  TMON/LQDT = 0 (не null) + `spanGaps: false`.
- FILL-04 ✅ (M) — раздельная непрозрачность штриховки: `hatchPattern`/
  `makeLayer` принимают `alpha` (кеш-ключ `color|angle|alpha`); LQDT → 0.99,
  дефолт HATCH_ALPHA 0.45.
- FILL-05 ✅ (M) — TGLD сплошная заливка: T `#2cba99` @ 30%; Финам `#4a7bd8`
  @ 12%, контур — тот же синий (alpha 0.9).

### Цель №3 — Чекбокс приростов и DPI
- CHK-01 ✅ (H) — чекбокс «изменения размера портфеля»
  (`invest_panel_change`) теперь гасит расчёт+показ суточных приростов
  (раньше влиял только на лейблы оси X).
- DPI-01 ✅ (M) — шрифты меток invest на 20% меньше (`labelFactor: 0.8` в
  `dpiFont`, weather не затронут): при росте DPI линии толстеют, шрифты
  не разрастаются.

### Цель №2 — Тул поиска/анализа/устранения артефактов данных ✅

**Симптом**: для ручной диагностики пришлось писать ad-hoc скрипты (scp+ssh
Python-скрипта в /tmp); процесс не переиспользуем.

**Решение**: `sh/data_scan.py` — один скрипт scan+fix по `invest_buckets`:
- `--list` — группы (source, res) и объёмы;
- по умолчанию — поиск окон провала (`close[i] < factor*base`, `min_run` подряд,
  возврат к норме; параметры `--factor 0.7`/`--min-run 2`);
- `--fix` — линейная интерполяция окна между соседями (OHLC+tgld_*), нормализация
  свечи, временный бэкап строк в `*_DELETE_AFTER_TEST`, печать SQL для проверки.
Работает с локальной копией БД и на проде (scp+ssh). Протестирован на
синтетике (окно 6×3.54M → интерполяция → scan чист) и на проде (`--list` ок,
`scan` чист после Цели №1).

**промпт:**

### Цель №5 — Метки не рисуются для отключённых серий ✅

**Симптом**: при выключенном в легенде портфеле (Tinkoff/Finam) метки
начала/конца/прироста продолжали висеть на графике.
**Решение**: `PeriodLabelsPlugin` пропускает источник, если его датасет скрыт
(`chart.isDatasetVisible(idx)`, fallback `ds.hidden`); матч по `s.datasetLabel`
(по умолчанию = `s.label`). Портфельным источникам задан
`datasetLabel: 'Tinkoff, ₽'` / `'Finam, ₽'` (wclock+hft).

**промпт:**
> В `PeriodLabelsPlugin` (`invest_chart.js`) пропускай источник, если его датасет скрыт (`chart.isDatasetVisible`); матч по `datasetLabel`; портфельным источникам задай `datasetLabel` `'Tinkoff, ₽'`/`'Finam, ₽'`.

**промпт:**

### Цель №7 — Настройка цветов тикеров в редакторе параметров ✅

**Симптом**: цвета TGLD/XAU/USD/Brent были захардкожены; изменить их из UI
(редактор «Параметры») было нельзя.
**Решение**: `chart_config.js` (wclock+hft) — в `DEFAULTS.color` добавлены
`tgld/xau/usd/brent`, в `SCHEMA` — группа **«Цвета тикеров»** (4 color-инпута).
`invest_chart.js` (wclock+hft) — `colorKey` у записей `TICKER_REGISTRY`, хелпер
`tickerColor(cfg)` (читает `color.<key>` из `ChartTheme`, fallback — дефолт),
применён в осях (`buildScales`), датасетах и placeholders; цвета период-меток —
через `ChartTheme.get`. `invest_banner.js` — хелпер `themeColor(key, def)`,
цвета строк входят в `hashBits` (чтобы DOM перерисовывался), слушатель
`chartThemeChange` → `updateInvestBanner()`. Цвет Brent — болотный `#556B2F`.
Группа «Цвета тикеров» выведена **последней группой второго столбца** (справа
от «Цвета линий»). hft: cache-bust `index.html` `?v=20261021.2`.

**промпт:**
> Добавь в `chart_config.js` (wclock+hft) `DEFAULTS.color.{tgld,xau,usd,brent}` и группу SCHEMA «Цвета тикеров»; в `invest_chart.js` — `colorKey`+`tickerColor(cfg)` для осей/датасетов/меток; в `invest_banner.js` — `themeColor(key,def)` + учёт цветов в `hashBits` + слушатель `chartThemeChange`; группу «Цвета тикеров» ставь последней во втором столбце.

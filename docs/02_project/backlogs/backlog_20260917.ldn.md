## Сводка
День 17.09: **медиатор данных клиент↔сервер** — единый `POST /api/data_mediator` с
токенизированной дельтой по секциям (вариант B): клиент шлёт токены секций,
сервер возвращает только изменившиеся (`{changed, tokens, ts}`), плюс
write-гранулярность батареи (`{applied, skipped}`). Секции: weather,
charts_data, battery (history + write), invest (history/tickers/turnover),
settings. Эпик `EPIC_mediator_data.md`.

  > В /api/data_mediator секцию battery.write обрабатывай по write_interval_battery;

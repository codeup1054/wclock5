### Цель №2 — 502 инвест-страницы: OOM-kill `wclock5-app` ✅

**Симптом**: `502 Bad Gateway` на `/api/invest/history`; в `docker events` —
`container oom, exit 137`.
**Причина**: `mem_limit 512m` (серверный `docker-compose.override.yml`) + unbounded
fallback в `morning_gap`: при пустом `period` вызывался `read_prices(None, ...)`,
грузивший **всю** историю `last_prices` (663k строк). Пик памяти на тесте
`tickers?period=-35 day` — ~264.7 MiB при ~111 MiB idle.
**Решение**: `mem_limit` 512m → **1g** (`docker compose up -d wclock`); убран
unbounded fallback из `/api/invest/ticker/<t>/morning_gap`.

**промпт:**
> Подними `mem_limit` контейнера `wclock5-app` 512m → 1g в серверном `docker-compose.override.yml` (`docker compose up -d wclock`); убери unbounded fallback `read_prices(None, ...)` из `/api/invest/ticker/<t>/morning_gap`.

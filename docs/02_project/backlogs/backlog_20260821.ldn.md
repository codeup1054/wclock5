## Сводка
День (21.08): **надёжность времени и mediation-слой данных инвестиций**.
Утром — мелкий UX (периоды «6 часов»/«3 часа», кнопка reload со сбросом кэша,
автоверсионирование статики). Основное — найден корень класса багов с
периодами графика: **несовпадение текстовых форматов времени** (демоны пишут
ISO `2026-08-21T08:13:08+00:00`, SQLite `datetime('now','-3 hour')` даёт
`2026-08-21 05:13:00`; при строковом сравнении `'T' > ' '` — все снапшоты
«сегодня» проходили любой фильтр, −3ч = −6ч = весь день).

Решение (одобрено владельцем): вариант **B + тонкий C** —
числовая колонка `ts_epoch` (Unix UTC) во всех таблицах + mediation-слой
`invest_repo.py` (timeutil, DTO, единая запись/чтение/retention).

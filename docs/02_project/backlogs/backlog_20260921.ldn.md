## Сводка
День 21.09: **фиксы статики прод-страницы wclock5 после Windows-сессии деплоя**
(ver 0.3) + **бандл «баннер ~10с»** (ver 0.4, ниже Цель №6)

1. **Краш инвест-баннера** `(dynHistory[… ] || []).map is not a function` на
   `invest_banner.js:687`: сервер с 10.09 кладёт в историю служебные ключи
   `_latest_epoch`/`_count` (комментарий контракта `invest_chart_helpers.js:327`),
   а фильтр списка timestamps исключал только `_prev`/`_api_errors`. Ключи `_…`
   сортируются лексикографически ПОСЛЕ числовых ts, поэтому «последний»
   элемент = `_latest_epoch` (число), и не-массив ловился в диагностическом
   `console.log` → TypeError, рвавший рендер.
2. **Направление ветра в прогнозе пустое**: текстовые `#fact_wind_dir`/
   `#forecast_1_wind_dir` писывались из `fact.wind_dir`/`forecast.wind_dir` — такого
   поля нет в схеме (`current`/`hourly_forecast` имеют `wind_direction`
   и `wind_dir_full`); стрелка-компас (`*_wind_dir_a`) была скрыта
   `display:none` при сеточном рефакторинге панели. По решению пользователя —
   вернули **вращающуюся стрелку** (grid-ячейки 1/3 и 2/3), вращение из
   `wind_direction` через `mailRuWindToDeg` (уже было в `index.js`).
3. **Авто-деплой при небольших правках**; на Windows-scp выявлены 2 подводных
   камня: `scp -r dir/ dst/` создаёт вложенную `dst/dir` (нужен `dir/.`),
   и новые каталоги получают права 700 → nginx отдаёт **403 Forbidden**
   (лечится `chmod 755` каталоги / `644` файлы).
4. **Ревизия кода investChart (анализ + правки)**: Mn-44 (инвертированный
   `labelMode`) ✅, Mn-45 (SPACING 18 + тайл 25, синхронизация hft) ✅,
   Mn-46 (`mergeDelta` O(n·m)) 🟡 отложено, Mn-47 (честный 0) ✅.

### Цель №4 — Деплой-процесс для Windows (авто-деплой при правках)
- Mn-43 ✅ (M) — правило «после небольших правок — деплой сразу, без `пп -дп»:
  `scp <файл>` → `chmod 644` файл / `755` каталог → `docker compose restart wclock`
  → MD5-сверка → `curl 200`. Для каталогов — `scp -r dir/. root@…:<dest>/`
  (вложенный `dst/dir` ломает деплой), после — обязательный `chmod` (иначе 403).

  > (Windows-scp даёт права 700→403); каталоги — `scp -r dir/. host:<dest>/` +
  > рестарт docker compose restart wclock + MD5.

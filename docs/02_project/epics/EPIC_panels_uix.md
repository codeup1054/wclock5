# Эпик — UI/UX панели: единая модалка Отчёты, баннер-панели, cqi

Изменения интерфейса панелей wclock5 за 03.09.2026: слияние настроек в
единую модалку Отчётов, настройки сбора через API, отдельная панель «Итого»,
CSS-скейлинг шрифтов баннера (container query), скрытие избыточных строк
при одном активном API.

## Контекст

Раньше настройки были в отдельной модалке `#panels-modal` (`lib.js`), а отчёты —
в `report.js` с кнопкой `O` (`#report_btn`). Плюс инвест-баннер показывал
строки по обоим источникам и итог даже когда API одного источника отключён.
За день интерфейс приведён к единой модалке и опционален по источникам.

## Правила UI (справочник)

1. **Единая точка входа модалки** — одна модалка на всё (отчёты+настройки),
   табы разделяют контент; не плодить отдельные модальные окна.
2. **Текущий таб подгружает данные** — если модалка открыта сразу на
   не-инвестиционном табе, переключение на «Инвестиции» вызывает `load()`
   (иначе таблица пустая: баг UI-01).
3. **Панель = опциональный элемент** — каждый автономный элемент инвест-баннера
   (Капитал / Таблица / Итого) — отдельная перетаскиваемая панель в `PANEL_IDS`
   и реестре `panel_configs.js`, с собственным переключателем в «Настройках».
4. **Источники опциональны** — при выключенном сборе (см. эпик API-настройки)
   источник и пара «T+F итог» не рендерятся; строка источника скрыта полностью.
5. **Шрифты баннера — cqi** — размеры в единицах контейнера (inline-size),
   чтобы ресайз панели масштабировал текст (см. conventions §6). Фикс. px — только
   для структурных неуправляемых элементов.
6. **Первый столбец таблицы периодов = тикер** — подпись тикера в первой ячейке
   (`banner-td-ticker`: `15px`, полужирный, по левому краю, `white-space:nowrap`)
   для всех строк; цвет тикера — из `ChartTheme` (`themeColor`).
7. **Строки-метрики = формат строк актива** — не-ценовые строки (напр. `Spread`)
   рендерятся теми же 8 колонками, что и тикеры: метка + значение за период +
   день/неделя/период (в % и абс.), чтобы таблица оставалась выровненной.
8. **Профиль настроек — файл, а не только localStorage** — экспорт даёт
   самодостаточный JSON (панели + профили + тема + все настройки), пригодный
   для переноса на другое устройство и для версионирования; серверная копия в
   `profiles/` — точка обмена, локальный файл — выбор пользователя.
9. **Нативный выбор файла — из жеста** — `showSaveFilePicker()` вызывается
   прямо в обработчике клика и **до** любого `prompt()`; `JSON.stringify`
   выполняется **до** `createWritable()` (тот сразу усекает файл: ошибка
   сериализации/сервера оставляла пустой файл).
10. **Баннер не теряет источник** — ретеншен сырых снапшотов обязан оставлять
    последнюю запись каждого `source`, иначе источник пропадает из
    `/api/invest/capital`, хотя данные в бакетах есть.
